CHAPTER 01

第 1 章｜認識 Antigravity、初次設定與 Turbo 模式攻略

五分鐘看懂 Antigravity 跟一般網頁版 AI 的差異，完成第一次啟動設定，並學會開啟 Turbo 模式省去重複點選確認。

1.1 為什麼老師需要 Google Antigravity？

網頁版聊天 AI 只能「給你文字建議」，老師還是得自己開 Word 調格式、一筆一筆下載學生影片、逐字把評語貼回 Padlet 或校務系統。Google Antigravity 是「代理型（Agentic）AI 工作平台」，它能讀懂老師設定的教學規準（Skills），並直接呼叫工具（MCP）幫您完成檔案整理、排版轉檔、網頁除錯與批次資料處理。

1.2 零基礎安裝與「第一次開啟」完整設定指南

🖥️ Antigravity 2.0 桌面版（首推）

獨立桌面應用程式，左側有對話紀錄、工作區專案、技能與 MCP 管理中心，最適合一般老師日常備課與批改使用。

💻 Antigravity IDE

AI 原生程式編輯器（類似 VS Code 介面），適合想要同時修改 HTML 互動教具或檢視腳本程式碼的老師。

⌨️ Antigravity CLI（agy）

輕量終端機介面，輸入 agy 即可快速啟動對話與執行指令，適合進階自動化排程。

📥 第一次下載安裝與初次啟動 5 步驟

  1. 下載並登入 Google 帳號：前往 Google Antigravity 官方頁面（https://antigravity.google）下載對應作業系統安裝檔（Windows / macOS）。安裝後開啟並使用 Google 帳號完成登入（若學校管理網域限制較多，建議優先用個人 Gmail 帳號）。
  2. 備齊兩套基礎執行環境：建議順手安裝 Python 3.10+ 與 Node.js 18+（第 2 章的 MCP 工具與第 3 章的作文紅筆批改／Word 轉檔腳本都需依賴這兩個環境）。
  3. 完成初次歡迎精靈與主題選擇：首次啟動時依畫面選擇偏好的淺色／深色介面；若系統詢問工作模式，教師日常備課推薦選用完整的代理模式（如 Agent / Knowledge Work）。
  4. 設定固定「工作區資料夾（Workspace / Open Folder）」：先在電腦建立一個專屬資料夾，例如 D:\教學AI工作區，接著點擊左側 Projects / Open Folder 開啟它。往後考卷、作文批改檔與互動網頁都會集中收在這裡。
  5. 認識對話輸入框下方選單並測試一句指令：在對話框下方可切換 執行模式（Planning 先列計畫再執行、Fast 快速處理）與 Gemini 模型。試著輸入「幫我在工作區建立一個『六上期中備課』資料夾」，看到 AI 成功建立資料夾即大功告成！

1.3 如何開啟 Turbo 模式？（省去一直跳窗按確認的困擾）

剛開始使用 Antigravity 時，系統預設會以較嚴格的「執行前詢問（Request Review）」模式保護電腦——每當 AI 想幫您跑 Python 轉檔腳本、批次整理 26 篇作文或執行本機工具時，就會停下來跳出 Run / Allow / Accept 按鈕等待老師手動點擊。如果您已選定安心的教學資料夾，建議改為 Turbo 模式（或 Always Proceed），讓 AI 一氣呵成幫您跑完批次作業！

⚡ 四步驟切換為 Turbo 模式

  1. 點開左側欄或右上角的 齒輪圖示 ⚙️（Settings）（快捷鍵 Ctrl + ,／Mac 為 Cmd + ,），進入 Agent Settings（代理程式設定）；部分版本也可直接在對話輸入框附近的權限下拉選單快速切換。
  2. 找到 Terminal Command Auto Execution（終端機指令自動執行） 或 Review Policy（審查政策 / Permission Preset）。
  3. 將預設的 Request Review（每次詢問） 或 Auto 切換為 Turbo（部分版本介面顯示為 Always Proceed／永遠自動執行）。
  4. 若您常把學生檔案放在桌面或下載資料夾，可同時將 Non-Workspace File Access（工作區外檔案存取） 調整為依需求放行，批改整批 PDF 時就不會卡住。

🛡️ 開 Turbo 安全嗎？老師必看的兩道雙重保障

  • 系統面：保留 Deny List（指令黑名單）：Turbo 模式會略過「逐次按確認」，但只要保留黑名單中的高風險系統指令（例如 rm -rf、格式化等破壞性命令），AI 就絕不會執行毀損電腦的動作。
  • 教學面：技能內建「先審核、後發布」鎖：開 Turbo 只加速本機讀檔、轉檔、截圖與排版；本手冊第 3、4、7 章凡是「對學生 Padlet 留言」或「寫入臺南市輔導系統」的技能，都已在 SKILL.md 寫死必須等老師點頭確認名單與內容才允許送出！
  • 彈性切回：若您偶爾要測試陌生來源的網路專案，隨時回到 Settings 切回 Request Review 即可。

1.5 三個馬上變高手的日常介面小技巧

  • 斜線指令（/）：在對話框輸入 /，就能喚出系統內建模式（如 /plan 先規劃再執行）或您安裝的教學技能（如 /chinese-quiz、/發布作文）。
  • 拖曳媒體直接問：把國語課本照片、學生手寫 PDF 或「說數學」影片直接拖進對話框，AI 會直接讀取畫面與聲音。
  • 用 @ 點名指定檔案：輸入 @ 即可快速選取工作區內的特定 Word、PDF 或題庫 .md 檔，讓 AI 精準聚焦不找錯檔案。

2.2 安全設定 mcp_config.json（已隱藏個人金鑰範本）

打開使用者設定檔 %USERPROFILE%\.gemini\config\mcp_config.json（Windows 可於檔案總管網址列輸入此路徑直達），貼入以下架構並將 <...> 替換成您自己的金鑰與程式路徑即可：

mcp_config.json（安全去敏範本） 
{
  "mcpServers": {
    "padlet": {
      "command": "npx.cmd",
      "args": ["-y", "padlet-mcp@latest"],
      "env": {
        "PADLET_API_KEY": "<請填入您自己的_PADLET_API_KEY>"
      }
    },
    "chrome-devtools": {
      "command": "npx.cmd",
      "args": ["-y", "chrome-devtools-mcp@latest", "--autoConnect"]
    },
    "notebooklm": {
      "command": "<您的PythonScripts路徑>\\notebooklm-mcp.exe",
      "args": []
    }
  }
}

2.3 如何讓 AI 連線您桌面上的 Chrome 瀏覽器？

  1. 在桌面 Chrome 瀏覽器網址列輸入 chrome://inspect/#remote-debugging，勾選 Enable remote debugging（允許遠端偵錯）。
  2. 或建立一個捷徑批次檔，以偵錯埠 9222 啟動 Chrome 專屬工作視窗。
  3. 資安優勢：所有需要校務帳密、OpenID 或驗證碼的網站（如命題大師、臺南市輔導系統），都由老師本人親自在 Chrome 完成登入，AI 完全不需要也不會紀錄您的密碼！
🔐 分享給同事前最重要的安全原則 切勿把自己的 mcp_config.json 或 .env 檔案直接傳給別人！裡面包含您個人的 PADLET_API_KEY 與 GEMINI_API_KEY。正確做法是只分享「技能資料夾（Skills）」與「空白佔位符範本」，讓每位老師申請並填入自己的金鑰。
CHAPTER 03

第 3 章｜教學實戰（一）：國語出題、作文診斷／紅筆批改與發布

把直書考卷排版交給自動化引擎，更將班級作文打磨成「先定寫作目的 → 審閱診斷報告書 → 依報告書大字紅筆批改 → Padlet 發布」的四步精準人機協作管線。

在國小國語科教學中，朕 老師將原本最耗時的考卷排版與 26 篇手寫作文批改，整合成四支互相銜接的標準化技能：不僅自動完成考卷直書與田字格排版，更確保 AI 在作文批改上絕不自作主張亂評分——一定要由老師先設定「會考六級分＋單篇寫作目的」，產出診斷報告書給老師看過定案後，才動用大字版紅筆套印原卷並發布至 Padlet。

✒️ 實戰案例：607 班「校慶徵文（26 篇原創寓言）」全自動診斷與紅筆原卷批改 針對全班 26 篇手寫原稿 PDF，朕 老師先設定「會考六級分規準＋必須原創寓言、不得沿用舊作情節」的寫作目的，由「會考六級分作文診斷報告書」技能批次產出 26 份本機 A4 Word 診斷報告書與六級分升級範文彙編，經老師審閱定案後，再啟動「原卷紅筆大字批改」依報告書產出大字清晰版紅筆批改 PDF（滿頁自動附空白末頁放置綜合診斷框，並逐頁轉圖確認紅圈完全對位不壓字），最後讓 Padlet 每個座號欄位都同時擁有「原稿掃描、寫作診斷報告書、紅筆原卷批改」三份完整檔案，學生與家長在手機上點開即可直接線上翻閱學習！

6.2 給同事的《數學遊戲開發提示詞（Prompt）》黃金五要素

為什麼同樣請 AI 寫遊戲，有些做出來只是陽春問答，朕 老師做出來的卻像商業級教材？關鍵在於下指令時同時寫清楚這 5 個維度：

  5. ⑤ 課後診斷履歷與（選配）試算表排行：結算列出答錯／思考過久題目，或自動生成 Google Apps Script 串接全班英雄榜。
