CHAPTER 01

第 1 章｜認識 Antigravity 與零基礎安裝指南

五分鐘看懂 Antigravity 跟一般網頁版 ChatGPT / Gemini 有何不同，並完成電腦端安裝。

1.1 為什麼老師需要 Google Antigravity？

網頁版聊天 AI 只能「給你文字建議」，老師還是得自己開 Word 調格式、一筆一筆下載學生影片、逐字把評語貼回 Padlet 或校務系統。Google Antigravity 是「代理型（Agentic）AI 工作平台」，它能讀懂老師設定的教學規準（Skills），並直接呼叫工具（MCP）幫您完成檔案整理、排版轉檔、網頁除錯與批次資料處理。

1.2 安裝步驟與介面選擇

🖥️ Antigravity 2.0 桌面版（首推）

獨立桌面應用程式，左側有對話紀錄、工作區專案、技能與 MCP 管理中心，最適合一般老師日常備課與批改使用。

💻 Antigravity IDE

AI 原生程式編輯器（類似 VS Code 介面），適合想要同時修改 HTML 互動教具或檢視腳本程式碼的老師。

⌨️ Antigravity CLI（agy）

輕量終端機介面，輸入 agy 即可快速啟動對話與執行指令，適合進階自動化排程。

📥 五分鐘安裝啟動流程

  1. 前往 Google Antigravity 官方頁面（https://antigravity.google）下載對應作業系統安裝檔（Windows / macOS）。
  2. 安裝後開啟應用程式並使用 Google 帳號完成登入授權。
  3. 建議同時準備 Python 3.10+ 與 Node.js 18+（許多好用的 MCP 工具與 Word/PDF 轉檔腳本皆依賴這兩個基礎環境）。
  4. 打開一個空白資料夾作為您的「工作區（Workspace）」，例如 D:\教學AI工作區，即可開始對話！

1.3 三個馬上變高手的介面小技巧

  • 斜線指令（/）：在對話框輸入 /，就能喚出系統內建模式（如 /plan 先規劃再執行）或您安裝的教學技能（如 /chinese-quiz、/發布作文）。
  • 拖曳媒體直接問：把國語課本照片、學生手寫 PDF 或「說數學」影片直接拖進對話框，AI 會直接讀取畫面與聲音。
  • 權限安全控制（Settings）：初次使用建議將終端機指令設為「執行前詢問（Request Review）」，AI 在寫入重要檔案或對外發文前都會先請您點確認。
CHAPTER 02

第 2 章｜替 AI 裝上萬用雙手：必裝 MCP 與外掛設定攻略

MCP（Model Context Protocol）是讓 Antigravity 連上 Padlet、Chrome 瀏覽器、NotebookLM 與 Google 雲端硬碟的關鍵橋樑。

2.1 洪偉朕老師實測必裝的核心 MCP 清單

MCP / 外掛名稱 對應工具與套件 在教學現場幫老師做什麼？ 需額外申請金鑰嗎？
Padlet MCP padlet-mcp@latest 自動建立班級分欄看板、讀取學生貼文與影音附件、批次發布評語留言。 需要個人 PADLET_API_KEY
Chrome DevTools MCP chrome-devtools-mcp@latest --autoConnect 連線老師桌面已登入的 Chrome 瀏覽器，擷取翰林命題大師題庫或同步臺南市輔導系統。 免金鑰（需開啟 Chrome 偵錯）
NotebookLM MCP notebooklm-mcp 直接查詢老師建在 NotebookLM 裡的研習講義、課程計畫與教學筆記。 透過個人 Google 帳號驗證
Google Workspace 外掛 Plugins：gdocs / gsheets / gslides / gdrive / gcalendar / gmail 直接在對話中建立與更新 Google 文件、試算表、簡報、日曆行事曆與雲端硬碟。 於 Plugins 介面一鍵登入授權
視覺設計與網站部署外掛 Plugins：canva / netlify / vercel / firebase 結合 Canva 進行海報簡報審閱，或將做好的互動教具網站直接部署上線。 依平台帳號授權連結

2.2 安全設定 mcp_config.json（已隱藏個人金鑰範本）

打開使用者設定檔 %USERPROFILE%\.gemini\config\mcp_config.json（Windows 可於檔案總管網址列輸入此路徑直達），貼入以下架構並將 <...> 替換成您自己的金鑰與程式路徑即可：

mcp_config.json（安全去敏範本） 
{
  "mcpServers": {
    "padlet": {
      "command": "npx.cmd",
      "args": ["-y", "padlet-mcp@latest"],
      "env": {
        "PADLET_API_KEY": "<請填入您自己的_PADLET_API_KEY>"
      }
    },
    "chrome-devtools": {
      "command": "npx.cmd",
      "args": ["-y", "chrome-devtools-mcp@latest", "--autoConnect"]
    },
    "notebooklm": {
      "command": "<您的PythonScripts路徑>\\notebooklm-mcp.exe",
      "args": []
    }
  }
}

2.3 如何讓 AI 連線您桌面上的 Chrome 瀏覽器？

  1. 在桌面 Chrome 瀏覽器網址列輸入 chrome://inspect/#remote-debugging，勾選 Enable remote debugging（允許遠端偵錯）。
  2. 或建立一個捷徑批次檔，以偵錯埠 9222 啟動 Chrome 專屬工作視窗。
  3. 資安優勢：所有需要校務帳密、OpenID 或驗證碼的網站（如命題大師、臺南市輔導系統），都由老師本人親自在 Chrome 完成登入，AI 完全不需要也不會紀錄您的密碼！
🔐 分享給同事前最重要的安全原則 切勿把自己的 mcp_config.json 或 .env 檔案直接傳給別人！裡面包含您個人的 PADLET_API_KEY 與 GEMINI_API_KEY。正確做法是只分享「技能資料夾（Skills）」與「空白佔位符範本」，讓每位老師申請並填入自己的金鑰。

第 9 章｜技能複製、雙向備份與推廣避坑清單

讓校內每位老師都能在 3 分鐘內複製並啟用這套教學技能庫。

9.1 同事如何把本手冊的技能複製到自己的電腦？

步驟一：找到技能存放資料夾

Antigravity 會自動讀取您電腦中的全域技能目錄：

%USERPROFILE%\.gemini\config\skills\

只要在裡面建立一個資料夾（例如 chinese-quiz-generator），並放入一個名為 SKILL.md 的檔案即可生效。

步驟二：貼上範本並重啟
